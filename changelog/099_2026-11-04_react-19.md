# 099 — React 19.3.1

**Date:** 2026-11-04
**Commit:** `377e008`
**Route:** unchanged

## Problem

The app was still on React 18.3.1. Next.js 16.3.3 already accepts React 19 (`^19.0.0`), so the runtime and the types were a major version behind the framework.

## Decision

Upgrade `react` and `react-dom` from `^18.3.1` to `^19.3.1`, and `@types/react` / `@types/react-dom` from the 18.3 line to `^19.3.0`. 19.3.1 is the latest stable 19.x that satisfies Next.js 16.3.3's peer range. No application source changed: there was no `useFormState`, `useFormStatus`, `forwardRef`, or removed React DOM API to migrate. `src` typechecks against the React 19 types.

The `(panel)` layout still renders `SiteNav` (and therefore `Panel`) once above `{children}`. Department and subsection links stay `next/link` routes inside that group.
